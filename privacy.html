Privacy policy

Last updated: 11 October 2026.

Episode uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channel. It has no other users.

What it accesses

With the consent of the channel's owner, the tool uses the YouTube Data API to upload a video, set its title, description and thumbnail, set the time at which it becomes public, and read back the status of that video. It does not read comments, subscribers, viewing data or any other content of the account.

What it stores

The tool keeps the authorisation token issued by Google, as an encrypted secret of the system that runs it, and a record of the videos it has uploaded (video identifier, upload time, scheduled release time). It stores no personal data about anyone else.

What it shares

Nothing. Data obtained through Google APIs is not sold, not transferred to third parties and not used for advertising. It is used only to carry out the uploads described above.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also relies on the YouTube Terms of Service and the Google Privacy Policy.

Withdrawing access

The owner can withdraw the tool's access at any time from the Google Account page, under "Third-party apps and services". After that the token no longer works and can be deleted from the system that held it.

Contact

Questions about this page can be raised through the issue tracker of the repository that hosts it.
